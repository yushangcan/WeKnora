2. 实现历史比较、CLI compare/gate 与自包含 CI；正常比较能够通过，答案退化和召回退化能够被检测并明确指出对应指标。

4. 增加 Embedding 结果缓存，支持 LRU/Redis、并发去重、模型配置隔离与失效降级；调整 Wiki 提示词为固定内容前置、动态内容后置。
5. 完成 PostgreSQL/SQLite 迁移回归、评测租约保护及 CI 验收，并整理真实 Luna 模型测试的原始与汇总证据。

三、验证结果

合成端到端验收覆盖四次 Run、八个 Case、正常比较、答案与 Recall 退化门禁、App 重启读回和数据库租约释放。

真实测试使用 gpt-5.6-luna 作为问答模型、BGE 作为 Embedding/Rerank，对 CMRC2018 的固定 20 问和 848 段语料运行 disabled、cold、warm 三组，均为 20/20 成功。三组 Recall、MRR、MAP、NDCG@3、NDCG@10 均为 1，Precision 为 0.7854。

warm 相对 cold 的测量窗口 Embedding 文本项从 1234 降至 1；关联评测 Run 的 Embedding 逻辑调用从 21 降至 0。准备耗时由 124297 ms 降至 622 ms。完整统计口径、Token 数据和原始记录均已归档，耗时差不作为生产环境收益承诺。
